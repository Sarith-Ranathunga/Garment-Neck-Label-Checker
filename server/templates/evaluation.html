A bypass is a size entered with no recognition attempt behind it; a fallback follows a genuine no read and is the escape hatch O1 requires. The two arrive on different endpoints, and the server — not the phone — writes the null that distinguishes them, so the figure cannot be flattered by the client. A high rate is a finding about the design, not a fault to be hidden.

An unresolved barcode is a gap in the barcode table, not a size error — the system does not know what that garment should be, which says nothing about the garment. Counting it as a mismatch would put a false positive against O2 and send an operator to pull a garment that is almost certainly correct. An unresolved rate above a few per cent is a finding about data entry, not about recognition.
